# Task Template

Toda tarefa passada a um agente de código deve seguir este formato:

```
Objetivo:
[uma frase, o que deve existir ao final]

Arquivos:
[quais arquivos serão criados ou alterados]

Regras:
[o que deve ser seguido — referenciar STACK.md / CODE_PATTERNS.md]

Critérios de aceite:
[como saber que a tarefa está pronta]

Arquivos proibidos:
[o que não pode ser tocado]

Testes:
[quais testes, se houver, devem ser criados ou continuar passando]

Documentação:
[o que precisa ser atualizado — CHANGELOG.md no mínimo]

Resultado esperado:
[o que o solicitante vai ver/testar ao final]
```

Nunca envie um pedido sem preencher pelo menos Objetivo, Arquivos, Critérios de aceite e Arquivos proibidos.
