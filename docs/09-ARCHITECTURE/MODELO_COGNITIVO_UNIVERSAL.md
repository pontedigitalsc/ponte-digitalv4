## 1. O que é uma empresa? — Visão Cognitiva

### 1.1 A definição jurídica não serve

Juridicamente, uma empresa é uma entidade com CNPJ, contrato social, obrigações fiscais e trabalhistas. Esta definição é útil para o Estado, mas inútil para compreender o que a empresa realmente é.

Contabilmente, uma empresa é um conjunto de ativos, passivos, receitas e despesas. Esta definição é útil para o fisco e para investidores, mas insuficiente para entender como a empresa funciona, decide, aprende ou fracassa.

### 1.2 A definição cognitiva

Uma empresa é um **sistema vivo de decisões** que:

1. **Transforma recursos em valor** para alguém (clientes, sociedade, proprietários).
2. **Aprende com o resultado** de cada transformação.
3. **Acumula conhecimento** sobre como fazer melhor.
4. **Decide sob incerteza** permanente sobre o futuro.
5. **Adapta-se** ao ambiente (mercado, regulação, concorrência, tecnologia).
6. **Repete padrões** que funcionam e **evita padrões** que falharam.
7. **Existe enquanto gera valor líquido positivo** para seus sustentadores.

### 1.3 A empresa como organismo cognitivo

```
                    ┌─────────────────────────────────────┐
                    │         AMBIENTE (Mercado)           │
                    │  Concorrência, Regulação, Clientes   │
                    └────────────────┬────────────────────┘
                                     │
                    ┌────────────────▼────────────────────┐
                    │         EMPRESA                     │
                    │                                     │
                    │  ┌─────────┐    ┌──────────┐       │
                    │  │ Recursos│───▶│ Processos │       │
                    │  │ (insumos)│   │ (operação)│       │
                    │  └─────────┘    └────┬──────┘       │
                    │                      ▼              │
                    │  ┌─────────┐    ┌──────────┐       │
                    │  │  Valor  │◀───│ Decisões │       │
                    │  │(output) │    │ (escolhas)│       │
                    │  └─────────┘    └────┬──────┘       │
                    │                      ▼              │
                    │  ┌─────────┐    ┌──────────┐       │
                    │  │Feedback │◀───│Conhecimento│       │
                    │  │(aprender)│   │ (memória) │       │
                    │  └─────────┘    └──────────┘       │
                    └─────────────────────────────────────┘
```

### 1.4 O que NÃO é uma empresa (cognitivamente)

| Não é | Por quê |
|-------|---------|
| Um CNPJ | O CNPJ é um identificador fiscal, não uma identidade operacional |
| Um contrato social | O contrato diz o que a empresa *pode* fazer, não o que *faz* |
| Um sistema de software | O sistema armazena dados, a empresa gera conhecimento |
| Um prédio | O prédio abriga, a empresa é feita de relações |
| Uma marca | A marca é a percepção externa, não a operação interna |
| Um produto | O produto é o que ela vende, não o que ela *é* |
| Um fluxo de caixa | O fluxo é consequência, não essência |

### 1.5 Implicação para a Ponte Digital

Se uma empresa é um **sistema vivo de decisões que aprende**, então compreender uma empresa significa:

1. Mapear suas **decisões críticas** (não apenas seus dados).
2. Mapear seu **ciclo de aprendizado** (não apenas seus resultados).
3. Mapear seus **padrões** (não apenas seus eventos).
4. Mapear suas **incertezas** (não apenas suas certezas).
5. Mapear sua **evolução** (não apenas seu estado atual).

## 2. Os 12 Elementos Universais

### 2.1 Descoberta fundamental

Após análise de 20+ segmentos empresariais, identificamos que **toda empresa — independentemente de porte, segmento ou maturidade — possui exatamente 12 elementos estruturais**. Estes elementos são universais porque derivam do que significa *ser uma empresa*: transformar recursos em valor no mercado.

### 2.2 Os 12 Elementos

```
┌─────────────────────────────────────────────────────────────┐
│                    OS 12 ELEMENTOS UNIVERSAIS                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. IDENTIDADE    ─  Quem é, onde está, como nasceu         │
│  2. PESSOAS       ─  Quem participa (interna e externamente)│
│  3. RECURSOS      ─  O que usa para operar                  │
│  4. OFERTA        ─  O que vende (produtos e serviços)      │
│  5. CLIENTES      ─  Para quem vende                        │
│  6. RELACIONAMENTO ─  Como se conecta com cada pessoa        │
│  7. PROCESSOS     ─  Como as coisas acontecem                │

## 3. Variação por Segmento

### 3.1 Princípio

Os 12 elementos universais estão presentes em **toda empresa**. O que varia por segmento é:

1. **O peso relativo** de cada elemento (finanças pesa mais em transportadora que em clínica)
2. **Os atributos específicos** de cada elemento (cliente de barbearia ≠ cliente de indústria)
3. **Os processos críticos** (agenda é crítica em clínica, estoque é crítico em loja)
4. **As decisões típicas** (o dono de restaurante decide cardápio, o dono de oficina decide peças)
5. **Os problemas mais comuns** (inadimplência em clínica, margem em restaurante)
6. **O vocabulário** (o que se chama de "cliente" vs "paciente" vs "aluno")

### 3.2 Matriz de Variação por Segmento

| Elemento | Comércio | Serviço | Indústria | Profissional Liberal |
|----------|----------|---------|-----------|-------------------|
| **Oferta** | Produto físico | Serviço intangível | Produto manufaturado | Conhecimento aplicado |
| **Cliente** | Pessoa comprando | Pessoa contratando | Empresa comprando | Pessoa contratando |
| **Processo crítico** | Comprar/Estocar/Vender | Atender/Agendar/Entregar | Produzir/Controlar qualidade | Atender/Captar cliente |
| **Recurso chave** | Estoque, ponto físico | Habilidade, agenda | Máquina, matéria-prima | Conhecimento, reputação |
| **Margem** | Baixa, giro alto | Alta, giro variável | Média, escala define | Alta, tempo limitado |
| **Problema típico** | Fluxo de caixa | Inadimplência | Custo fixo alto | Tempo ocioso |

### 3.4 Variação por Porte

| Dimensão | MEI (~1 pessoa) | ME (~10 pessoas) | EPP (~50 pessoas) | Média (~200+) |
|----------|----------------|-------------------|-------------------|---------------|
| Decisão | Centralizada no dono | Dono + 1 gerente | Diretoria | Conselho + CEO |
| Processo | Informal | Semi-estruturado | Estruturado | Formal |

## 4. Representação Cognitiva em 7 Camadas

### 4.1 O problema da representação

Um banco de dados relacional representa fatos. Uma ontologia representa significados. Um grafo representa conexões. Nenhum deles, isoladamente, representa o que uma empresa *é* cognitivamente.

A representação cognitiva exige 7 camadas, cada uma respondendo a uma pergunta diferente:

```
7 camadas de representação cognitiva

┌──────────────────────────────────────────────────────────────┐
│  7. CONHECIMENTO ─ O que aprendemos com tudo isso?           │
│     "Padrões, princípios, regras de negócio, sabedoria"      │
├──────────────────────────────────────────────────────────────┤
│  6. APRENDIZADO ─ Como evoluímos?                            │
│     "Ciclos, feedback, correções, melhorias, erros"           │
├──────────────────────────────────────────────────────────────┤
│  5. RESULTADOS ─ O que aconteceu?                            │
│     "Indicadores, métricas, sucessos, fracassos"             │
├──────────────────────────────────────────────────────────────┤
│  4. EVENTOS ─ O que ocorreu?                                 │
│     "Transações, interações, mudanças, incidentes"           │
├──────────────────────────────────────────────────────────────┤
│  3. PROCESSOS ─ Como funciona?                               │
│     "Fluxos, procedimentos, rotinas, decisões"               │
├──────────────────────────────────────────────────────────────┤
│  2. RELACIONAMENTOS ─ Quem se conecta com quem?              │
│     "Contratos, vínculos, interações, dependências"          │
├──────────────────────────────────────────────────────────────┤
│  1. ENTIDADES ─ Quem e o que existe?                         │
│     "Pessoas, recursos, ofertas, lugares"                    │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 Cada camada explicada

#### Camada 1 — Entidades

O inventário do que existe. Objetos nomeados com atributos.

```
Empresa "Barbearia do João"
├── Pessoa: João (dono, barbeiro)
├── Pessoa: Carlos (barbeiro)
├── Pessoa: Maria (recepcionista)
├── Recurso: Cadeira 1, Cadeira 2, Cadeira 3
├── Recurso: Tesoura profissional, Máquina de cortar
├── Oferta: Corte masculino (R$ 45)
├── Oferta: Barba (R$ 25)
├── Oferta: Corte + Barba (R$ 60)
└── Local: Rua Augusta, 123
```

#### Camada 2 — Relacionamentos

Como as entidades se conectam.

```
João → dono → Barbearia do João
João → trabalha → Barbearia do João (como barbeiro)
Carlos → trabalha → Barbearia do João (como barbeiro)
Maria → trabalha → Barbearia do João (como recepcionista)
Cliente Pedro → cliente → Barbearia do João
Cliente Pedro → cortou com → João (15/07/2026)
Fornecedor BelezaBella → fornece → Tesoura profissional
```

#### Camada 3 — Processos

Sequências de ações que transformam.

```
Processo: Atendimento
1. Cliente chega → Maria recepciona
2. Maria pergunta → "Corte ou barba?"
3. Cliente senta → na cadeira disponível
4. Barbeiro executa → o serviço contratado
5. Cliente paga → dinheiro/cartão/pix
6. Maria registra → na agenda do dia

Processo: Comprar insumos
1. João percebe → tesoura está cega
2. João compra → nova tesoura online
3. Tesoura chega → em 3 dias
4. João testa → tesoura nova
5. João descarta → tesoura velha
```

#### Camada 4 — Eventos

Ocorrências que marcam o tempo.

```
15/07 09:00 → Evento: Cliente Pedro chegou
15/07 09:00 → Evento: João iniciou atendimento
15/07 09:25 → Evento: Atendimento concluído
15/07 09:25 → Evento: Pagamento recebido (R$ 60, Pix)
15/07 09:25 → Evento: Cliente Pedro saiu
15/07 10:00 → Evento: Cliente chegou sem agendamento
15/07 10:05 → Evento: Maria encaixou cliente na agenda
```

#### Camada 5 — Resultados

Consequências mensuráveis dos eventos.

```
Resultado do dia: Receita R$ 720 (16 cortes)
Resultado da semana: Receita R$ 3.400, 72 atendimentos
Resultado do mês: Receita R$ 14.200, Despesa R$ 8.500, Lucro R$ 5.700
Resultado do mês: Ticket médio R$ 47,50
Resultado do mês: Ocupação das cadeiras: 67%
Resultado do mês: Clientes novos: 12, Clientes recorrentes: 60
```

#### Camada 6 — Aprendizado

O que a empresa mudou com base nos resultados.

```
Aprendizado (Julho):
  - "Segunda-feira é dia mais fraco → fechar uma cadeira"
  - "Clientes preferem Pix a dinheiro → incentivar Pix"
  - "Corte + Barba é o combo mais vendido → criar combos"
  - "Tesoura X dura mais → comprar só essa marca"
```

#### Camada 7 — Conhecimento

Padrões estáveis que orientam decisões futuras.

```
Conhecimento estabelecido:
  - "Ticket médio sobe 15% quando oferecemos combo no início"
  - "Melhor horário para agendamento: 9h-11h e 14h-17h"
  - "Cliente fiel gasta 3x mais que cliente novo"
  - "Investir em tesoura boa reduz tempo de corte em 20%"
  - "Agendamento online reduz faltas em 40%"
```

## 5. Ciclo de Vida da Empresa

### 5.1 Como uma empresa nasce

Uma empresa não nasce quando o CNPJ é emitido. Ela nasce cognitivamente quando:

1. **Alguém identifica** uma oportunidade: "As pessoas precisam de X e ninguém faz bem perto daqui."
2. **Alguém decide arriscar** tempo e dinheiro para criar X.
3. **Alguém executa** a primeira venda — a troca real de valor por dinheiro.
4. **O ciclo se completa**: o primeiro cliente paga, a empresa entrega, o cliente fica satisfeito (ou não).

O nascimento cognitivo é **a primeira transação completa e consciente**. Antes disso, é apenas uma ideia.

### 5.2 Como uma empresa cresce

```
Fase 1 — Sobrevivência
├── Foco: Fazer o primeiro mês fechar
├── Decisão principal: O que cortar quando falta dinheiro
├── Aprendizado crítico: O que o cliente realmente quer
└── Risco: Acabar o caixa antes de aprender

Fase 2 — Estabilidade
├── Foco: Repetir o que funciona
├── Decisão principal: Contratar ou não contratar
├── Aprendizado crítico: O que é lucrativo de verdade
└── Risco: Ficar preso no operacional

Fase 3 — Eficiência
├── Foco: Fazer mais com menos
├── Decisão principal: Onde investir para escalar
├── Aprendizado crítico: O que pode ser delegado
└── Risco: Perder a qualidade crescendo

Fase 4 — Expansão
├── Foco: Novos mercados, produtos, canais
├── Decisão principal: Qual risco vale a pena
├── Aprendizado crítico: O que não fazer
└── Risco: Crescer rápido demais e quebrar

Fase 5 — Maturidade
├── Foco: Sustentar o que construiu
├── Decisão principal: Inovar ou otimizar
├── Aprendizado crítico: Como se reinventar
└── Risco: Ser disruptado por quem vem de baixo
```

### 5.3 Como uma empresa aprende

```
Evento → Observação → Reflexão → Hipótese → Teste → Aprendizado

Exemplo real:
  "Perdi 3 clientes essa semana" (evento)
  "Eles reclamaram de demora" (observação)
  "Talvez seja porque só tenho 1 barbeiro" (reflexão)
  "Se eu contratar mais um barbeiro, atendo mais clientes" (hipótese)
  "Contratei o Carlos por 3 meses" (teste)
  "Atendimento subiu 40%, custo subiu 20%, lucro subiu" (aprendizado)
```

### 5.4 Como uma empresa muda

A mudança ocorre em 4 padrões:

| Padrão | Gatilho | Velocidade | Risco |
|--------|---------|------------|-------|
| **Reativa** | Crise (perdeu cliente grande, cash parou) | Rápida | Alto — decisão sem análise |
| **Antecipatória** | Sinal (concorrente mudou, lei nova) | Moderada | Médio — pode ser cedo demais |
| **Incremental** | Aprendizado (descobriu algo que melhora) | Lenta | Baixo — ajuste controlado |
| **Transformacional** | Visão (decidiu ser outra coisa) | Variável | Muito alto — muda essência |

### 5.5 Como uma empresa entra em crise

A crise não é um evento. É um **ciclo de reforço negativo**:

```
Problema inicial
    ↓
Decisão errada (ou nenhuma decisão)
    ↓
Resultado pior
    ↓
Menos opções disponíveis
    ↓
Mais pressão
    ↓
Decisão pior ainda
    ↓
Efeito dominó
    ↓
CRISE
```

**Gatilhos comuns de crise:**
- Dependência concentrada (1 cliente = 80% da receita)
- Crescimento sem estrutura (vendeu mais do que consegue entregar)
- Perda de pessoa-chave (dono adoece, funcionário essencial sai)
- Choque externo (pandemia, crise econômica, regulação)
- Erosão silenciosa (margem caindo há meses, ninguém percebeu)

### 5.6 Como uma empresa melhora

A melhoria é um **ciclo de reforço positivo**:

```
Perceber um problema ou oportunidade
    ↓
Decidir agir
    ↓
Agir de forma diferente
    ↓
Medir o resultado
    ↓
Comparar com antes
    ↓
Validar que melhorou
    ↓
Incorporar a mudança como novo padrão
    ↓
(volta ao início)
```

## 6. Hierarquia Dado → Sabedoria

### 6.1 Os 5 níveis

```
                    ┌─────────────────────────────────────┐
                    │         SABEDORIA                   │
                    │   "Por que isso importa?"           │
                    │   Princípios, valores, propósito     │
                    └────────────────┬────────────────────┘
                                     │
                    ┌────────────────▼────────────────────┐
                    │        CONHECIMENTO                  │
                    │   "Como funciona?"                  │
                    │   Padrões, modelos, regras           │
                    └────────────────┬────────────────────┘
                                     │
                    ┌────────────────▼────────────────────┐
                    │         CONTEXTO                     │
                    │   "O que significa?"                │
                    │   Relações, causas, efeitos          │
                    └────────────────┬────────────────────┘
                                     │
                    ┌────────────────▼────────────────────┐
                    │       INFORMAÇÃO                     │
                    │   "O que aconteceu?"                │
                    │   Dados organizados, categorizados   │
                    └────────────────┬────────────────────┘
                                     │
                    ┌────────────────▼────────────────────┐
                    │           DADO                       │
                    │   "O que é?"                        │
                    │   Sinal bruto, sem significado       │
                    └─────────────────────────────────────┘
```

### 6.2 Cada nível aplicado a uma empresa

| Nível | Exemplo na barbearia | O que permite fazer |
|-------|---------------------|---------------------|
| **Dado** | "R$ 45" | Nada — é só um número |
| **Informação** | "Corte masculino custa R$ 45" | Saber o preço do serviço |
| **Contexto** | "Corte masculino é 60% dos atendimentos e tem margem de 70%" | Saber o que mais gera lucro |
| **Conhecimento** | "Clientes que fazem corte + barba voltam 2x mais e gastam 40% mais" | Decidir estratégia de vendas |
| **Sabedoria** | "Nosso negócio não é cortar cabelo — é fazer o homem se sentir bem cuidado. Por isso investimos em ambiente, conversa e experiência, não apenas em preço." | Definir propósito, cultura, posicionamento |

### 6.3 O papel da IA na hierarquia

| Nível | O que a IA pode fazer | O que a IA NÃO pode fazer |
|-------|----------------------|--------------------------|
| Dado | Coletar, armazenar, limpar | Criar dado onde não existe |
| Informação | Categorizar, somar, comparar | Dar significado sem contexto |
| Contexto | Correlacionar, historizar, segmentar | Saber o que é relevante sem feedback |
| Conhecimento | Identificar padrões, sugerir hipóteses | Validar hipóteses sem resultado real |
| Sabedoria | *Nada* — sabedoria é humana | Substituir o julgamento do empresário |

## 8. Fontes de Descoberta da IA

### 8.1 Princípio

A IA descobre respostas através de múltiplos canais. Nenhum canal isolado é suficiente. A verdade sobre uma empresa emerge da **convergência de fontes independentes**.

### 8.2 Mapa completo de fontes

```
FONTES DE DESCOBERTA
├── ATIVAS (IA inicia)
│   ├── Conversa
│   │   ├── Pergunta direta
│   │   ├── Pergunta adaptativa (segue resposta anterior)
│   │   ├── Confirmação ("Entendi corretamente?")
│   │   └── Escavação ("Me conte mais sobre...")
│   ├── Observação
│   │   ├── Comportamento do usuário na plataforma
│   │   ├── Padrões de uso (o que mais acessa, o que ignora)
│   │   └── Tempo gasto em cada ação
│   └── Sugestão
│       ├── "Você sabia que pode importar seus clientes?"
│       └── "Notei que você nunca registrou despesas — quer ajuda?"
│
├── PASSIVAS (IA recebe)
│   ├── Documentos
│   │   ├── PDF (contratos, boletos, relatórios)
│   │   ├── Planilhas (Excel, CSV, Google Sheets)
│   │   ├── Imagens (fotos de notas, comprovantes)
│   │   ├── Documentos fiscais (XML NFe, NFCe)
│   │   └── Texto livre (Word, TXT)
│   ├── Integrações
│   │   ├── ERP (Omie, Bling, ContaAzul, SAP)
│   │   ├── CRM (RD Station, HubSpot, Pipedrive)
│   │   ├── Bancos (extrato, conciliação)
│   │   ├── Agenda (Google Calendar, Outlook)
│   │   └── E-commerce (Shopify, Loja Integrada)
│   ├── Mensagens
│   │   ├── WhatsApp Business (conversas, pedidos)
│   │   ├── E-mail (propostas, contratos)
│   │   └── Redes Sociais (menções, avaliações)
│   └── Histórico
│       ├── Ações anteriores na plataforma
│       ├── Conversas passadas
│       └── Decisões registradas
│
├── REATIVAS (IA responde a estímulo)
│   ├── Feedback do usuário
│   │   ├── Correção ("Isso está errado")
│   │   ├── Confirmação ("Isso está certo")
│   │   └── Complemento ("Faltou dizer que...")
│   └── Alerta
│       ├── Mudança detectada (nota fiscal diferente do padrão)
│       └── Anomalia (venda muito acima da média)
│
└── INFERIDAS (IA deduz)
    ├── Dedução lógica (CNPJ → segmento → tributos prováveis)
    ├── Correlação (cliente que compra X também compra Y)
    ├── Padrão estatístico (ticket médio X em dezembro)
    └── Analogia (empresas similares têm estrutura similar)
```

Qual fonte é melhor para descobrir cada elemento:

| Elemento | Melhor fonte | Segunda fonte | Fonte de validação |

| Pessoas | Conversa | Integração (folha, ERP) | Documentos |
| Recursos | Observação | Integração (estoque) | Conversa |
| Oferta | Conversa | Documentos (site, catálogo) | Integração (vendas) |
| Clientes | Integração (vendas) | Documentos (planilha) | Conversa |
| Relacionamento | Mensagens | Conversa | Observação |
| Processos | Conversa | Observação | Documentos |
| Finanças | Integração (banco) | Documentos (planilha) | Conversa |
| Decisões | Conversa | Histórico | Observação |
| Aprendizado | Histórico | Conversa | Feedback |
| Problemas | Conversa | Observação | Feedback |
| Ambiente | Inferência | Conversa | Documentos |

## 9. Modelo de Confiança

### 9.1 O problema

A IA nunca pode ter certeza absoluta sobre uma empresa. Toda informação coletada tem um grau de confiança que depende da fonte, do método, do contexto e da consistência.

Precisamos de um modelo que responda: **quanto a IA pode confiar no que ela "sabe" sobre esta empresa?**

### 9.2 Níveis de confiança

```
NÍVEL        VALOR     SIGNIFICADO
─────────────────────────────────────────────────────────────
Confirmado    1.00     Empresário confirmou explicitamente
Alta          0.85     Múltiplas fontes convergentes
Média         0.65     Fonte única confiável (documento oficial)
Baixa         0.40     Inferência com evidência indireta
Suspeita      0.20     Fonte não confiável ou contraditória
Desconhecido  0.00     Nenhuma informação disponível
```

### 9.3 Matriz de confiança por fonte

| Fonte | Confiança base | Fatores de ajuste |
|-------|---------------|-------------------|
| Empresário disse explicitamente | 0.90 | -0.10 se contradito depois |
| Documento oficial (NF, contrato) | 0.85 | -0.15 se desatualizado |
| Integração direta (ERP via API) | 0.80 | -0.20 se integração parcial |
| Planilha enviada pelo empresário | 0.55 | -0.15 se manual, +0.10 se frequente |
| Extração de PDF/OCR | 0.45 | +0.15 se validação humana |
| Inferência da IA | 0.30 | +0.20 se baseada em múltiplos padrões |
| Conversa indireta ("meu funcionário disse") | 0.40 | -0.15 se terceiro |
| Observação de comportamento | 0.35 | +0.20 se padrão consistente |
| Dado público (CNPJ, redes sociais) | 0.50 | -0.20 se desatualizado |
| Analogia com empresas similares | 0.15 | +0.10 se segmento muito similar |

### 9.4 Regras de decisão

| Condição | Ação da IA |
|----------|-----------|
| Confiança ≥ 0.85 | Pode afirmar como fato |
| Confiança entre 0.50 e 0.84 | Apresentar como hipótese: "Acredito que..." |
| Confiança entre 0.20 e 0.49 | Perguntar: "Isso está correto?" |
| Confiança < 0.20 | Permanecer em silêncio — não usar a informação |
| Duas fontes contraditórias com confiança ≥ 0.50 | Apresentar ambas: "Fonte A diz X, fonte B diz Y" |
| Confiança caindo com novo dado | Rebaixar nível, perguntar novamente |

## 10. Ciclo de Nascimento do Conhecimento

### 10.1 O ciclo completo

O conhecimento não nasce pronto. Ele emerge de um ciclo que transforma eventos brutos em patrimônio cognitivo.

```
                    ┌─────────────────────────────────┐
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │       EVENTO BRUTO            │                  │
    │   "Cliente reclamou"          │                  │
    └───────────────┬───────────────┘                  │
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │       REGISTRO                │                  │
    │   "Dia 15/07, 14h, cliente    │                  │
    │    reclamou de demora"        │                  │
    └───────────────┬───────────────┘                  │
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │       PADRÃO                  │                  │
    │   "3 reclamações de demora    │                  │
    │    neste mês, todas 14h-16h" │                  │
    └───────────────┬───────────────┘                  │
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │       HIPÓTESE               │                  │
    │   "Demora ocorre porque só   │                  │
    │    tem 1 barbeiro no horário  │                  │
    │    de almoço"                │                  │
    └───────────────┬───────────────┘                  │
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │       TESTE                   │                  │
    │   "Agendar 2 barbeiros no    │                  │
    │    horário 14h-16h por 2 sem."│                  │
    └───────────────┬───────────────┘                  │
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │       VALIDAÇÃO               │                  │
    │   "Reclamações caíram 80%.   │                  │
    │    Custo subiu 5%, receita    │                  │
    │    subiu 15%."               │                  │
    └───────────────┬───────────────┘                  │
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │    CONHECIMENTO VALIDADO      │                  │
    │   "Ter 2 barbeiros no horário │                  │
    │    de pico reduz reclamações  │                  │
    │    e aumenta receita líquida" │                  │
    └───────────────┬───────────────┘                  │
                    │                                  │
    ┌───────────────▼───────────────┐                  │
    │   PATRIMÔNIO COGNITIVO        │                  │
    │   Armazenado, versionado,     │                  │
    │   indexado, reutilizável      │                  │
    └───────────────────────────────┘                  │
                    │                                  │
    └──────────────────────────────────────────────────┘
        (O conhecimento vira base para novo ciclo)
```

### 10.2 Ciclo simplificado (8 estágios)

```
1. PERCEBER  →  Algo aconteceu ou mudou
2. REGISTRAR →  Capturar o fato com proveniência
3. ANALISAR  →  Encontrar padrões, correlações
4. HIPOTETIZAR → Propor explicação causal
5. TESTAR    →  Agir com base na hipótese
6. MEDIR     →  Comparar resultado com antes
7. VALIDAR   →  Confirmar ou refutar a hipótese
8. INCORPORAR → Adicionar ao patrimônio cognitivo
```

### 10.3 O que pode dar errado

| Problema | Efeito | Como evitar |
|----------|--------|-------------|
| Viés de confirmação | IA só vê o que confirma hipótese | Buscar ativamente evidência contrária |
| Ruído | Padrão falso por coincidência | Exigir N mínimo de ocorrências |
| Causalidade falsa | Correlação tratada como causa | Sugerir, nunca afirmar causalidade |
| Amostra pequena | Padrão de 2 eventos generalizado | Marcador "evidência insuficiente" |
| Esquecimento | Conhecimento validado é perdido | Patrimônio Cognitivo versionado |

## 11. Modelo de Incerteza

### 11.1 A incerteza é inerente

Nenhuma empresa será totalmente conhecida. A incerteza não é um bug — é uma propriedade do mundo real. A Ponte Digital deve operar **com** incerteza, não tentar eliminá-la.

### 11.2 Os 5 estados de certeza

```
ESTADO          DESCRIÇÃO                          AÇÃO DA IA
──────          ──────────                          ─────────
Certeza         Informação confirmada por          Pode usar para decidir
                múltiplas fontes consistentes
                ou pelo próprio empresário

Hipótese        Informação plausível, mas          Pode sugerir, deve avisar
                não confirmada                     que é hipótese

Suspeita        Informação contraditória ou        Não usar — perguntar
                de fonte não confiável

Desconhecido    Nenhuma informação disponível      Perguntar ou buscar

Contradição     Duas fontes dizem coisas           Apresentar ambas,
                incompatíveis                      nunca escolher
```

### 11.3 Matriz de incerteza

Para cada informação, armazenar:

| Campo | Descrição | Exemplo |
|-------|-----------|---------|
| Valor | O conteúdo da informação | "Ticket médio: R$ 47" |
| Estado | Certeza/Hipótese/Suspeita/Desconhecido/Contradição | Hipótese |
| Confiança | Score numérico (0.0 a 1.0) | 0.55 |
| Fonte | De onde veio | "Planilha enviada em 15/07" |
| Data | Quando foi coletada | 15/07/2026 |
| Validade | Até quando é razoável assumir que ainda vale | 15/10/2026 |
| Contradições | Lista de fontes que dizem o contrário | ["NF 4523: R$ 52"] |
| Lacunas | O que está faltando para confirmar | "Precisa de NFs dos últimos 3 meses" |

### 11.4 Propagação de incerteza

Quando uma informação é usada para inferir outra, a incerteza se propaga:

```
Se:
  A = "João tem 3 clientes/dia" (confiança 0.70)
  B = "João trabalha 22 dias/mês" (confiança 0.90)

Então:
  C = "João atende 66 clientes/mês"
  Confiança(C) = min(0.70, 0.90) × 0.85 = 0.595
  (O fator 0.85 é a penalidade da inferência)

Regra: Confiança(inferência) = min(confianças das fontes) × penalidade
       onde penalidade = 0.85 para inferência direta
                         0.70 para inferência indireta
                         0.50 para inferência analógica
```

## 12. Modelo de Evolução

### 12.1 A empresa no tempo

Uma empresa não é um instantâneo. Ela é uma **trajetória**. O modelo cognitivo deve capturar:

```
Passado                    Presente                    Futuro
  │                          │                          │
  ▼                          ▼                          ▼
[Antes] ─────────────────── [Agora] ────────────────── [Depois]
  │                          │                          │
  ├─ Fundação                ├─ Estado atual             ├─ Planos
  ├─ Eventos marcantes       ├─ Problemas ativos        ├─ Metas
  ├─ Aprendizados           ├─ Decisões pendentes      ├─ Riscos previstos
  ├─ Erros                  ├─ Oportunidades           ├─ Oportunidades
  ├─ Versões anteriores      ├─ Conhecimento validado   ├─ Cenários
  └─ Ciclos completados      └─ Ciclo em andamento      └─ Hipóteses
```

### 12.2 Versionamento cognitivo

Cada informação deve ter versões:

```
Conhecimento: "Ticket médio"
  v1 (15/01/2026): R$ 42 — Fonte: Conversa inicial
  v2 (20/03/2026): R$ 45 — Fonte: 3 NFs analisadas
  v3 (10/07/2026): R$ 47 — Fonte: 47 NFs do período
  Estado atual: v3 (confiança 0.85)
  Tendência: Crescente (+R$ 5 em 6 meses)
```

### 12.3 Linha do tempo cognitiva

```
Jul 2025 ── Fundação da Barbearia do João
Set 2025 ── Primeiro cliente (evento fundador)
Nov 2025 ── Percebeu que cliente quer barba + corte
Jan 2026 ── Lançou combo Corte + Barba (decisão)
Mar 2026 ── Contratou Carlos (aprendizado: precisa de 2)
Jun 2026 ──── Crise: Carlos pediu demissão
Jul 2026 ── Contratou Maria e Pedro

## 15. Processo de Reconstrução da Empresa

### 15.1 O problema da tábula rasa

Quando a Ponte Digital encontra uma empresa pela primeira vez, ela não sabe nada. Zero. A reconstrução é o processo de **ir do zero ao conhecimento máximo possível** através da convergência de fontes.

### 15.2 As 8 fases da reconstrução

```
FASE 0 — IDENTIFICAÇÃO INICIAL
────────────────────────────────────────────────────────────
Entrada: CNPJ ou nome ou contato
 Saída: Identidade mínima (segmento, porte, localização)
 Fontes: CNPJ, conversa inicial, dados públicos
 Esforço: 1 minuto
 Confiança: 0.30 - 0.50
 Flags: [segmento_identificado, porte_estimado]

FASE 1 — ESQUELETO
────────────────────────────────────────────────────────────
Entrada: Identidade mínima
 Saída: Estrutura básica (quem são as pessoas, o que vendem)
 Fontes: Conversa, site, redes sociais
 Esforço: 5-10 minutos
 Confiança: 0.40 - 0.60
 Flags: [pessoas_mapeadas, oferta_identificada]

FASE 2 — OPERAÇÃO
────────────────────────────────────────────────────────────
Entrada: Esqueleto
 Saída: Como funciona (processos, recursos, agenda)
 Fontes: Conversa aprofundada, observação, documentos
 Esforço: 15-30 minutos
 Confiança: 0.50 - 0.70
 Flags: [processos_mapeados, recursos_identificados]

FASE 3 — FINANÇAS
────────────────────────────────────────────────────────────
Entrada: Operação
 Saída: Fluxo financeiro (receitas, despesas, margens)
 Fontes: Integração (banco, ERP), planilhas, NFs, conversa
 Esforço: 30-60 minutos
 Confiança: 0.50 - 0.80
 Flags: [financas_mapeadas, margem_calculada]

FASE 4 — CLIENTES
────────────────────────────────────────────────────────────
Entrada: Operação + Finanças
 Saída: Quem compra, como compra, por que compra
 Fontes: Integração (vendas), conversa, mensagens
 Esforço: 20-40 minutos
 Confiança: 0.50 - 0.75
 Flags: [clientes_mapeados, jornada_identificada]

FASE 5 — PROBLEMAS E DECISÕES
────────────────────────────────────────────────────────────
Entrada: Tudo acima
 Saída: O que impede a empresa de crescer, como decide
 Fontes: Conversa, histórico, feedback
 Esforço: 15-30 minutos
 Confiança: 0.40 - 0.70
 Flags: [problemas_identificados, decisoes_mapeadas]

FASE 6 — CONHECIMENTO
────────────────────────────────────────────────────────────
Entrada: Tudo acima
 Saída: Padrões, aprendizados, regras do negócio
 Fontes: Análise cruzada de todas as fases
 Esforço: Contínuo (não é uma fase discreta)
 Confiança: 0.30 - 0.85
 Flags: [conhecimentos_extraidos, padroes_identificados]

FASE 7 — VALIDAÇÃO
────────────────────────────────────────────────────────────
Entrada: Modelo completo (com lacunas e incertezas)
 Saída: Modelo validado pelo empresário
 Fontes: Perguntas de confirmação, correção do empresário
 Esforço: 10-20 minutos
 Confiança: 0.70 - 0.95
 Flags: [modelo_validado, lacunas_preenchidas]
```

### 15.3 Reconstrução em cenários reais

| Cenário | Fases puladas | Estratégia |
|---------|--------------|------------|
| Empresário só respondeu conversa | 3, 4 (parcial) | Estimativas com confiança baixa, mais perguntas |
| Empresa conectou ERP completo | 2, 3, 4 aceleradas | Dados estruturados substituem conversa |
| Empresa mandou 5 planilhas | 3, 4 (parcial) | Extrair, validar, perguntar o que faltar |
| Empresa tem WhatsApp integrado | 4, 5 (parcial) | Clientes e problemas emergem das conversas |
| Empresa não responde nada | Nenhuma (todas) | Apenas dados públicos (confiança muito baixa) |

## 16. Estados Cognitivos da Empresa

### 16.1 A empresa no espectro cognitivo

Uma empresa não é "conhecida" ou "desconhecida". Ela existe em um **espectro contínuo de estados cognitivos**, que evolui à medida que a Ponte Digital adquire, valida e conecta informações.

### 16.2 Os 9 estados cognitivos

```
ESTADO          DEFINIÇÃO                          CONDIÇÃO PARA ENTRAR
──────          ──────────                          ───────────────────
Desconhecida    Nada se sabe além do CNPJ          Primeiro contato
                ou identificação mínima

Superficial     Sabe-se o segmento, porte          Identidade mínima
                e localização                       (Fase 0 concluída)

Estrutural      Sabe-se quem são as pessoas,       Esqueleto montado
                o que vendem e como se organizam   (Fase 1 concluída)

Operacional     Sabe-se como funciona:             Operação mapeada
                processos, recursos, agenda         (Fase 2 concluída)

Financeira      Sabe-se o fluxo de caixa,          Finanças mapeadas
                margens e resultados               (Fase 3 concluída)

Comercial       Sabe-se quem são os clientes,      Clientes mapeados
                como compram e por que ficam/vao    (Fase 4 concluída)

Diagnosticada   Sabe-se quais problemas a          Problemas e decisões
                impedem de crescer                 (Fase 5 concluída)

Cognitiva       Sabe-se os padrões, regras,        Conhecimento extraído
                aprendizados e o patrimônio         (Fase 6 concluída)
                cognitivo da empresa

Validada        O empresário confirmou ou          Validação concluída
                corrigiu o modelo cognitivo        (Fase 7 concluída)
                completo
```

### 16.3 Transições entre estados

```
Desconhecida ──► Superficial ──► Estrutural ──► Operacional
                                        │              │
                                        │              ▼
                                        │        Financeira
                                        │              │
                                        │              ▼
                                        └────► Comercial
                                                      │
                                                      ▼
                                                Diagnosticada
                                                      │
                                                      ▼
                                                Cognitiva
                                                      │
                                                      ▼
                                                Validada
```

### 16.4 Regressão de estado

Uma empresa pode regredir de estado se:

1. **Informação se desatualiza** (não é revisitada há N meses)
2. **Contradição aparece** (nova fonte contradiz o que se sabia)
3. **Empresa muda** (abriu nova unidade, mudou de segmento)
4. **Confiança cai** (fonte original se mostrou não confiável)

### 16.5 Estado composto

Uma empresa pode estar em estados diferentes para cada elemento:

```
Empresa: Barbearia do João
├── Identidade:       Validada (empresário confirmou)
├── Pessoas:          Estrutural (sabe quem, não sabe habilidades)
├── Oferta:           Validada (cardápio completo confirmado)
├── Finanças:         Operacional (sabe receita, não sabe margem)
├── Clientes:         Comercial (lista de clientes, sem histórico)
├── Processos:        Diagnosticada (sabe o gargalo)
└── Conhecimento:     Cognitiva (padrões identificados)
```

Isto permite que a IA saiba **onde focar** para evoluir o estado geral.
