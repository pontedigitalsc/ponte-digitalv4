# Sistema Oficial de Narrativa

Cada tela da Ponte Digital conta uma história. Não apresenta dados.

## Princípio

> "O empresário não veio ler relatório. Ele veio descobrir algo sobre a própria empresa. Cada tela é um capítulo dessa descoberta."

## Estrutura Narrativa de Cada Tela

1. **Gancho** — o que prende a atenção (primeira coisa que o empresário vê/lê)
2. **Contexto** — onde estamos na história (o que já foi descoberto)
3. **Conflito** — o que ainda não sabemos (a pergunta/desafio atual)
4. **Descoberta** — o que acabamos de aprender (o insight/dado novo)
5. **Próximo capítulo** — para onde vamos (próxima pergunta/ação)

## Aplicação por Tela

### Landing
| Elemento | Conteúdo |
|---|---|
| Gancho | "A inteligência da sua empresa" |
| Contexto | — (primeiro contato) |
| Conflito | "O que você ainda não sabe sobre seu negócio?" |
| Descoberta | — (acontece depois do diagnóstico) |
| Próximo | "Começar descoberta" |

### Conversa (primeira pergunta)
| Elemento | Conteúdo |
|---|---|
| Gancho | "Vou conhecer sua empresa" |
| Contexto | "Somos novos aqui" |
| Conflito | "Para te ajudar, preciso primeiro entender" |
| Descoberta | "Cada resposta revela algo novo" |
| Próximo | "Próxima pergunta" |

### Conversa (insight)
| Elemento | Conteúdo |
|---|---|
| Gancho | "Encontrei um padrão" + ✦ |
| Contexto | o que já sabemos |
| Conflito | "Isso pode ser um gargalo" |
| Descoberta | o insight em si |
| Próximo | "Vamos investigar mais" |

### Diagnóstico final
| Elemento | Conteúdo |
|---|---|
| Gancho | "Conheço sua empresa" |
| Contexto | resumo do que foi descoberto |
| Conflito | "Ainda existem lacunas" |
| Descoberta | principais insights |
| Próximo | "Ver dashboard completo" |

### Dashboard
| Elemento | Conteúdo |
|---|---|
| Gancho | "Sua empresa em [data]" |
| Contexto | "Este é o retrato atual" |
| Conflito | "Áreas que precisam de atenção" |
| Descoberta | "Novos insights desde sua última visita" |
| Próximo | "Nova conversa" / "Explorar recomendação" |

## Regras de Narrativa

1. Toda tela precisa de **gancho** (primeira linha/valor que prende)
2. Toda tela precisa de **próximo passo** (nunca dead end)
3. A história sempre **avança** (nunca repete o mesmo estado)
4. O **empresário é o protagonista** (a IA é a narradora)
5. Dados são a **evidência** da história (nunca o foco)
