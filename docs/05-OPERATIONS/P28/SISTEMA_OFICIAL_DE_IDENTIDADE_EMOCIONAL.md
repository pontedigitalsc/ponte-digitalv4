# SISTEMA OFICIAL DE IDENTIDADE EMOCIONAL

> **Propósito:** Mapear como o empresário deve se sentir em cada clique, cada resposta, cada insight.
> **Fase:** V4 Founder — cada emoção conta na validação do produto.
> **Data:** Julho 2026

---

## Regras de Identidade Emocional

1. **Toda interação gera emoção** — neutralidade não é opção. Até o silêncio comunica.
2. **Cada momento tem uma emoção-alvo** — o sentimento é planejado, nunca aleatório.
3. **Emoções negativas são mapeadas e mitigadas** — todo risco emocional conhecido tem um plano de resposta.
4. **A transição emocional é suave** — emoções não mudam abruptamente. O empresário é conduzido.

---

## O Mapa Emocional

### Clique no CTA "Começar"

**Emoção-alvo:** Antecipação positiva, curiosidade

**Sinais de que acertamos**
- Empresário clica sem hesitar
- Sorriso ou expressão de curiosidade
- Movimento para frente no assento

**O que NÃO sentir**
- Ansiedade ("e se eu não souber responder?")
- Desconfiança ("isso vai me custar quanto?")
- Confusão ("o que eu faço aqui?")

**O que a interface deve comunicar**
- "Isso é simples. Você já tem as respostas — só não sabe ainda."
- Prompt inicial acolhedor: "Vamos começar? Você vai se surpreender com o que já sabe sobre sua empresa."
- Zero jargão técnico. Zero pedidos complexos.

**Mitigação de risco emocional**
- Explicar em 1 linha o que vai acontecer: "Vou fazer algumas perguntas sobre sua empresa."
- Botão de "só explorar" para quem não quer se comprometer
- Mostrar barra de progresso antes de começar (saber quanto tempo leva)

---

### Responde a Primeira Pergunta

**Emoção-alvo:** Alívio ("era fácil"), confiança inicial

**Sinais de que acertamos**
- Empresário avança rapidamente para próxima pergunta
- Resposta é natural, sem hesitação
- Comentário tipo: "ok, isso foi tranquilo"

**O que NÃO sentir**
- Arrependimento ("já estou preso nisso?")
- Frustração ("não sei responder isso")
- Impaciência ("mais uma pergunta?")

**O que a interface deve comunicar**
- A primeira pergunta deve ser a mais fácil — algo que o empresário sabe de cor
- Feedback imediato positivo: "Ótimo! Essa informação já ajuda."
- Barra de progresso animada (mostrar que está avançando)

**Mitigação de risco emocional**
- Se empresário hesitar > 5s: surgir dica contextual
- Se empresário pular pergunta: "Sem problema, podemos voltar depois"
- Se resposta for vaga: IA reformula sem julgar

---

### IA Mostra Primeira Conexão

**Emoção-alvo:** Admiração ("ela entendeu"), surpresa positiva

**Sinais de que acertamos**
- Empresário faz "oh!" ou "nossa"
- Compartilha com alguém ao lado
- Lê a conexão mais de uma vez

**O que NÃO sentir**
- Ceticismo ("qualquer um faria essa conexão")
- Indiferença ("ok, e daí?")
- Descrença ("isso é muito óbvio para ser inteligente")

**O que a interface deve comunicar**
- A conexão aparece com destaque sutil (Glow de Insight)
- A IA demonstra que lembrou de algo que o empresário disse antes
- Revelação no timing certo: não instantâneo, não demorado

**Mitigação de risco emocional**
- Se a conexão for fraca: IA admite "isso ainda está simples, mas com mais dados fica melhor"
- Se o empresário discordar: "Me mostre onde errei" (aceitar correção graciosamente)

---

### Recebe Primeiro Insight

**Emoção-alvo:** Descoberta ("não tinha pensado nisso"), valor percebido

**Sinais de que acertamos**
- Empresário faz anotação mental ou física
- Pausa para refletir (olhar para o lado, para cima)
- "É... realmente faz sentido."

**O que NÃO sentir**
- Indiferença ("isso é óbvio")
- Desconfiança ("será que é verdade?")
- Sobrecarga ("é muita informação")

**O que a interface deve comunicar**
- O insight é apresentado com o Anel de Confiança visível
- "Isso é interessante porque..." (contexto, não só dado)
- A evidência está a um clique de distância (fonte do insight)

**Mitigação de risco emocional**
- Insight deve ser curto (3 linhas no máximo)
- Opção de "explorar mais" ou "entendi, próximo"
- Se confiança baixa: "Isso é uma hipótese — o que você acha?"

---

### Corrige a IA

**Emoção-alvo:** Controle, satisfação ("ela aceitou a correção")

**Sinais de que acertamos**
- Empresário sente que foi ouvido
- Continua interagindo normalmente (sem trauma)
- Se sentir confortável para corrigir de novo

**O que NÃO sentir**
- Frustração ("ela não entendeu")
- Raiva ("ela insiste no erro")
- Impotência ("não adianta corrigir")

**O que a interface deve comunicar**
- IA agradece a correção genuinamente: "Entendi, obrigado. Isso me ajuda a ser mais precisa."
- O erro corrigido desaparece ou é marcado como "corrigido"
- O novo entendimento é refletido imediatamente

**Mitigação de risco emocional**
- IA nunca argumenta com a correção (aceita incondicionalmente)
- Se a correção contradiz dado anterior: "Você disse X antes, isso mudou?" (pergunta, não acusa)
- Histórico de correções visível (empresário vê que sua contribuição foi registrada)

---

### Vê o Diagnóstico Final

**Emoção-alvo:** Clareza, visão do todo, confiança alta

**Sinais de que acertamos**
- Empresário olha o diagnóstico completo em silêncio
- Expressão de compreensão ("agora entendo o quadro")
- Pergunta sobre próximos passos (não sobre o diagnóstico em si)

**O que NÃO sentir**
- Sobrecarga ("muita informação")
- Dúvida ("e agora?")
- Arrependimento ("não era isso que eu queria")

**O que a interface deve comunicar**
- Visão hierárquica: do macro (sua empresa) para o micro (áreas específicas)
- O diagnóstico conta uma história (não é só dados jogados)
- Insights mais importantes destacados visualmente

**Mitigação de risco emocional**
- Versão resumo (3 pontos) e versão completa
- "E agora?" com recomendações claras
- Diagnóstico salvo automaticamente (nunca perder)

---

### Retorna para Segunda Sessão

**Emoção-alvo:** Continuidade, pertencimento ("ela lembrou de mim")

**Sinais de que acertamos**
- Empresário reconhece a sessão anterior
- Continua de onde parou naturalmente
- Sensação de que "valeu a pena voltar"

**O que NÃO sentir**
- Recomeço ("tudo de novo")
- Estranhamento ("não parece familiar")
- Culpa ("faz tempo que não entro")

**O que a interface deve comunicar**
- Momento Zero: saudação personalizada com contexto da última sessão
- "Na última vez você descobriu que..."
- Ambiente exatamente como foi deixado (estado preservado)

**Mitigação de risco emocional**
- Se passou muito tempo: "Muita coisa pode ter mudado. Quer atualizar algo?"
- Se parou no meio: "Você estava explorando [tópico]. Quer continuar?"
- Nunca fazer o empresário se sentir culpado pela ausência

---

### Vê Evolução no Dashboard

**Emoção-alvo:** Orgulho ("minha empresa está evoluindo"), parceria

**Sinais de que acertamos**
- Empresário navega pelo dashboard com curiosidade
- Compara indicadores atuais com anteriores
- Tira print ou mostra para alguém

**O que NÃO sentir**
- Estagnação ("é sempre a mesma coisa")
- Ansiedade ("minha empresa não está evoluindo")
- Indiferença ("não mudou nada")

**O que a interface deve comunicar**
- Toda mudança positiva é destacada: "Você evoluiu 23% em Gestão desde o último mês"
- Barra de Conhecimento mostra progresso visível
- Dashboard celebra avanços (sem exageros)

**Mitigação de risco emocional**
- Se não houve evolução: "Tudo bem — conhecimento também é sobre se preparar. Vamos juntos?"
- Se houve regressão: "Isso é normal. Ciclos de negócio têm altos e baixos. O importante é saber onde está."
- Nunca comparar empresas (cada jornada é única)

## Tabela de Emoções por Estado

| Estado | Emoção-alvo | Risco emocional | Mitigação |
|--------|------------|-----------------|-----------|
| Entrada (primeira vez) | Ansiedade → Curiosidade | Abandono | Prompt acolhedor, sem jargão |
| Primeira pergunta | Incerteza → Alívio | Bloqueio | Pergunta mais fácil primeiro |
| Processamento IA | Impaciência → Expectativa | Abandono | Anel de Confiança + barra |
| Insight revelado | Surpresa → Descoberta | Ceticismo | Glow + evidência visível |
| Correção | Frustração → Controle | Raiva/abandono | Aceitação incondicional |
| Dashboard | Curiosidade → Orgulho | Sobrecarga | Hierarquia visual + resumo |
| Retorno | Esquecimento → Pertencimento | Estranhamento | Momento Zero + contexto |
| Longa ausência | Culpa → Aceitação | Abandono | "Tudo bem, vamos retomar" |
| Erro do sistema | Raiva → Perdão | Abandono definitivo | Transparência + compensação |

## Princípios de Design Emocional

1. **Primeiro sentimento, depois funcionalidade** — antes de o empresário entender, ele já sentiu
2. **Microemoções importam** — um "obrigado" no lugar certo muda a percepção
3. **Emoção negativa não é falha — é oportunidade** — bem tratada, gera mais confiança que acerto
4. **Consistência emocional** — o tom não muda entre telas, entre dias, entre dispositivos
5. **O silêncio também emociona** — saber quando não falar é tão importante quanto saber o que dizer
