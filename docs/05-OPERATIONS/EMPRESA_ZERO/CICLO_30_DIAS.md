# Primeiro Ciclo de 30 Dias — Protocolo

**Propósito:** Estruturar os primeiros 30 dias de operação real da Empresa Zero, transformando cada ação em dado cognitivo.

---

## Dia 0 — Marca Zero

### Checklist de partida

- [ ] Deploy funcionando (Vercel ou ambiente acessível)
- [ ] Empresa Zero criada no sistema (`cms17tcgu0000g4vrmuq11cgw`)
- [ ] Fundador consegue fazer login
- [ ] Fundador consegue navegar entre os módulos principais
- [ ] Diário Cognitivo criado (este documento)
- [ ] Repositório publicado no GitHub (WP-20.5 pendente)

### Primeiros dados a inserir

O fundador deve registrar manualmente no sistema:

1. **Empresa:** Dados da Ponte Digital (nome, segmento, porte)
2. **Primeiro lead:** Quem é o primeiro lead real ou fictício
3. **Primeira transação:** O custo inicial da operação (hospedagem, ferramentas, etc.)
4. **Primeira tarefa:** "Concluir deploy da Ponte Digital"

### Registro cognitivo inicial

No Diário Cognitivo:

```
DESCOBERTA: O que senti ao entrar no sistema da minha própria empresa pela primeira vez?
HIPÓTESE: Clientes sentirão o mesmo que estou sentindo agora?
DECISÃO: O primeiro módulo que vou usar é...
```

## Dias 1-7 — Imersão Operacional

### O que fazer

Cada dia, o fundador deve usar o sistema como se fosse um cliente pagante:

| Dia | Atividade no sistema | Registro cognitivo |
|-----|---------------------|--------------------|
| 1 | Criar 3 leads fictícios (perfis de clientes ideais) | Facilidade/dificuldade de criar lead |
| 2 | Mover leads no pipeline (CONTATO → DIAGNOSTICO → PROPOSTA) | O pipeline reflete a realidade? |
| 3 | Registrar 3 transações financeiras | O modelo financeiro faz sentido? |
| 4 | Criar 5 tarefas operacionais | Que tipos de tarefa aparecem? |
| 5 | Usar o assistente IA | A IA entende o contexto da empresa? |
| 6 | Navegar pelo Knowledge Vault | O conhecimento faz sentido? |
| 7 | Revisão semanal | O que aprendi? |

### O que registrar

- **Processos:** Como cada fluxo realmente funciona vs. como imaginei
- **Dificuldades:** Onde o sistema atritou em vez de ajudar
- **Dúvidas:** O que não ficou claro
- **Fricções:** Onde desisti ou pulei uma etapa

### Perguntas-guia para cada dia

1. Se eu fosse um cliente pagante, o que eu estaria sentindo agora?
2. O que me fez perder tempo hoje?
3. O que me surpreendeu positivamente?
4. O que eu mostraria para um amigo empresário?

---

## Dias 8-15 — Identificação de Padrões

### O que fazer

Revisar os primeiros 7 dias em busca de padrões:

| Área | O que procurar | Exemplo de padrão |
|------|----------------|-------------------|
| Comportamento | Sequências de ações repetidas | "Sempre abro o CRM antes do Dashboard" |
| Produto | Funcionalidades ignoradas | "Nunca cliquei no Centro de Decisão" |
| Processo | Etapas quebradas | "Lead foi direto de CONTATO para FECHADO" |
| Cognitivo | Aprendizados que se repetem | "Toda semana aprendo algo sobre finanças" |
| Técnico | Erros ou lentidão | "Assistente demora > 5s para responder" |

### Perguntas para encontrar padrões

1. O que eu fiz todos os dias?
2. O que eu NUNCA fiz?
3. O que foi mais repetitivo?
4. Onde gastei mais tempo?
5. O que me fez sentir mais produtivo?

### Entrega desta etapa

Lista de 3-5 padrões identificados, registrados no Diário Cognitivo como descobertas.

- [ ] Deploy estável (sem erros críticos)
