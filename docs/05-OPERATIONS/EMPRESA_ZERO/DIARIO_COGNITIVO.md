# Diário Cognitivo da Empresa Zero

**Propósito:** Registrar tudo que a Empresa Zero está ensinando sobre administrar uma empresa usando a própria Infraestrutura Cognitiva que está sendo construída.

**Instrução:** Preencher diariamente. Cada entrada deve responder: "O que a realidade está ensinando?"

---

## Estrutura de Cada Entrada

### Descobertas

Observações factuais sobre como o negócio funciona na prática.

```
DATA: [data]
CATEGORIA: [Produto | Processo | Comportamental | Técnico | Negócio]
RELATO: [descrição factual do que foi observado]
CONTEXTO: [em que situação isso apareceu]
IMPACTO: [por que isso importa]
```

### Hipóteses

Suposições testáveis sobre o negócio, produto ou comportamento.

```
DATA: [data]
HIPÓTESE: [descrição clara e testável]
EVIDÊNCIA ATUAL: [o que já sabemos até agora]
COMO TESTAR: [ação específica que confirmaria ou rejeitaria]
STATUS: [NOVA | EM TESTE | CONFIRMADA | REJEITADA]
```

### Evidências

Dados concretos que confirmam ou rejeitam hipóteses.

```
DATA: [data]
REFERÊNCIA: [hipótese ou descoberta relacionada]
FONTE: [observação direta | dado do sistema | feedback | conversa]
DADO: [informação concreta]
PESO: [ALTA | MÉDIA | BAIXA — quão confiável é esta evidência]
```

### Decisões

Decisões tomadas com base no que foi aprendido.

```
DATA: [data]
DECISÃO: [o que foi decidido]
MOTIVO: [por que foi decidido]
ALTERNATIVAS: [o que foi considerado mas rejeitado]
BASE: [quais evidências ou descobertas levaram a esta decisão]
IMPACTO ESPERADO: [o que esperamos que aconteça]
```

### Aprendizados

Conhecimento consolidado que permanece.

```
DATA: [data]
APRENDIZADO: [frase curta que captura o conhecimento]
CATEGORIA: [Valores | Preferências | Regras | Objetivos | Rotinas | ...]
CONFIANÇA: [0-100 — quão certo estamos disso]
REVISÕES: [quantas vezes este aprendizado foi validado]
```

## Campos de Indexação

Para facilitar a consulta futura, cada entrada deve conter:

- **tags:** `[comercial, operação, financeiro, produto, cognitivo]`
- **envolvidos:** `[fundador, lead, cliente, parceiro]`
- **estado emocional:** `[confiante, incerto, frustrado, surpreso, neutro]`

---

## Primeiras Perguntas para o Diário

Estas perguntas ajudam a começar:

1. O que aconteceu hoje que eu não esperava?
2. Qual foi a decisão mais difícil que tomei?
3. O que um novo membro da equipe precisaria saber?
4. Se eu pudesse mudar uma coisa no sistema hoje, o que seria?
5. O que um cliente pagante sentiria ao usar o sistema agora?
6. Qual padrão estou começando a perceber?
7. O que ficou mais claro hoje do que estava ontem?
