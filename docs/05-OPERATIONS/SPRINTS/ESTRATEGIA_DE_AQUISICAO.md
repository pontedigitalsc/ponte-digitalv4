# Estratégia de Aquisição — P48

## Objetivo
Levar empresários reais ao diagnóstico, gerar valor imediato (revelação + retrato), criar vínculo (Apoiador) e converter em jornada contínua (criação de conta).

## Onde abordar

### Canais orgânicos (sem custo)
- LinkedIn: posts sobre "O peso de administrar uma empresa" com link direto para `/diagnostico`
- WhatsApp: compartilhamento do link do diagnóstico por contatos próximos
- Indicação boca a boca: empresários que fizeram o diagnóstico indicarem para outros

### Canais diretos
- Abordagem pessoal do Founder em eventos, reuniões, redes de contato
- Empresários conhecidos recebem link personalizado do diagnóstico

## Fluxo do visitante

```
1. Landing (/ ou link direto)
   → "O peso invisível de administrar uma empresa"
   → CTA: "Entender minha empresa" → /diagnostico

2. Diagnóstico (/diagnostico)
   → Múltipla escolha: "Qual dessas situações mais parece sua realidade?"
   → 4 perguntas abertas
   → Revelação: 3 itens (força, atenção, oportunidade)
   → Retrato Inicial (5 dimensões)
   → Identidade: Apoiador AP-XXXXX
   → 3 caminhos: explorar / criar jornada / ser Fundador

3. Pós-diagnóstico
   → Visitante leva: revelação + retrato + número de Apoiador
   → Se criar conta: jornada contínua começa com "Minha empresa hoje"
   → Se não criar: pode refazer o diagnóstico e explorar o site
```

## Métricas de sucesso (aprendizado, não metas)

- Quantas pessoas chegam ao diagnóstico?
- Quantas completam as 5 perguntas?
- Quantas veem a revelação até o fim?
- Quantas clicam em "criar jornada"?
- O que empresários reais falam sobre a experiência?
- Quais perguntas geram mais reflexão?

## Próximos passos naturais

- Testar com 1 empresário real → ajustar perguntas e tom
- Se aprendizado positivo: expansão para mais canais
- Se aprendizado negativo: reformular abordagem

## O que NÃO fazer agora

- Anúncios pagos (sem dado de conversão)
- Landing page complexa (a atual serve)
- Sistema de recomendação (seria engenharia pesada sem evidência)
