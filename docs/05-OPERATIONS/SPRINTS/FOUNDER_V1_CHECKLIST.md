# Founder V1 — Checklist de Validação

## Uso: empresário validando a plataforma

---

## 1. Primeiro Contato

- [ ] Criar conta em <30 segundos
- [ ] Login funciona (e-mail + senha)
- [ ] Saudação personalizada ("Bom dia, {nome}")
- [ ] Centro Diário é a primeira tela após login
- [ ] Centro Diário responde 5 perguntas:
  - Onde estamos
  - O que mudou
  - O que merece atenção
  - Quem precisa de você
  - Próximo movimento

## 2. Rotina Diária

- [ ] Abrir Atendimento em 1 clique
- [ ] Buscar cliente por nome em <3 segundos
- [ ] Cliente reconhecido com último serviço
- [ ] Confirmar atendimento em ≤3 cliques
- [ ] Atendimento registrado aparece no Caixa do Dia
- [ ] Timeline Mini mostra eventos do dia
- [ ] Sem telas de confirmação desnecessárias
- [ ] Zero formulários longos

## 3. Cliente Novo

- [ ] Criar cliente sem sair do Atendimento
- [ ] Nome + serviço + valor em ≤15 segundos
- [ ] Cliente aparece nas listas imediatamente

## 4. Consultas

- [ ] Timeline mostra história completa da empresa
- [ ] Conhecimento mostra aprendizados acumulados
- [ ] Decisões mostra recomendações
- [ ] Caixa mostra extrato vivo do dia
- [ ] Pessoas lista todos os clientes

## 5. Aprendizado

- [ ] Assistente responde perguntas sobre a empresa
- [ ] Aprendizados mostra o que foi registrado
- [ ] Sugestões aparecem baseadas no histórico

## 6. Interface

- [ ] Sidebar tem grupos: Trabalho / Consultar / Aprender / Sistema
- [ ] Toda tela carrega em <2 segundos
- [ ] Zero termos técnicos (engine, score, outcome, cognitivo na UI)
- [ ] Zero gráficos sem contexto
- [ ] Zero páginas que não respondem "qual capacidade fortalece?"

## 7. Critérios de Bloqueio

Se QUALQUER item abaixo falhar, a plataforma não está pronta para Founder:

- [ ] Atendimento não carrega
- [ ] Busca de cliente não funciona
- [ ] Não é possível registrar um atendimento
- [ ] Caixa não atualiza após atendimento
- [ ] Erro 500 em qualquer tela principal
- [ ] Qualquer termo "Engine" visível na interface
