# Registro de Hipóteses

*Este é o registro canônico. `02-PRODUCT/CURRENT_PRODUCT.md` seção 4 lista as mesmas hipóteses em prosa, como lembrete rápido — este arquivo é onde o status de cada uma é rastreado ao longo do tempo. Nenhuma hipótese aqui é verdade até validar com uso real dos 100 fundadores. Ao validar ou invalidar uma, mover o aprendizado para `VALIDATED_LEARNINGS.md` e atualizar o status abaixo.*

## Status possíveis

- **Não testada** — ainda não há dado real de uso.
- **Em teste** — sprint ativa está coletando evidência.
- **Validada** — evidência real confirma; aprendizado registrado em `VALIDATED_LEARNINGS.md`.
- **Invalidada** — evidência real contradiz; não implementar como se fosse verdadeira, registrar o porquê aqui mesmo, na coluna Evidência.

## Como adicionar uma hipótese nova

Toda sprint nova que assumir algo não comprovado sobre o comportamento do empresário deve registrar a hipótese aqui (ver `05-OPERATIONS/SPRINTS/TEMPLATE.md`, seção "Hipóteses desta sprint") — não só na cabeça de quem está implementando.
